# E-commerce Sales Analysis Dashboard

## 📊 Project Overview
This project presents an interactive Power BI dashboard designed to analyze e-commerce sales data and monitor business performance across products, categories, regions, and time periods.

## 🎯 Objectives
- Analyze total sales, profit, and order trends
- Identify top-performing products and categories
- Track regional sales performance
- Support data-driven business decisions

## 🛠 Tools Used
- Power BI Desktop
- CSV / Excel Dataset
- GitHub

## 📌 Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Sales Growth

## 📈 Visualizations
- KPI Cards
- Bar & Column Charts
- Line Chart (Sales Trend)
- Category & Region Analysis
- Interactive Slicers
